# 🧪 Jest Practice

A collection of unit testing examples built with **Jest**, showcasing different testing techniques in JavaScript/TypeScript applications.

This repository is intended for learning, experimenting, and understanding how to write reliable and maintainable tests using Jest.

---

## 🚀 Features

- ✅ Unit Testing
- ✅ Test Suites
- ✅ Assertions & Matchers
- ✅ Mock Functions
- ✅ Async Testing
- ✅ Code Coverage
- ✅ Organized Test Structure
- ✅ Easy-to-understand examples

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/manishchettrikarki/jest.git

cd jest
```

Install dependencies

```bash
npm install
```

or

```bash
pnpm install
```

---

## ▶️ Running Tests

Run all tests

```bash
npm test
```

Watch mode

```bash
npm test -- --watch
```

Generate coverage report

```bash
npm test -- --coverage
```

## 📖 Example

```javascript
function sum(a, b) {
  return a + b;
}

test("adds two numbers", () => {
  expect(sum(2, 3)).toBe(5);
});
```
